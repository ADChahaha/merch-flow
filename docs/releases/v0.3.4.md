## 修复

- 修复 Windows 安装包的本地编码不匹配：harness 可能按 GBK 输出，而父进程按 UTF-8 读取，导致 `read��in_progress��`、中文日志乱码或非 GBK 字符输出失败。
- 程序入口和独立 CLI 显式使用 UTF-8 标准输入输出，PyInstaller 同时固定 UTF-8 模式；不再仅依赖打包解释器可能忽略的 `PYTHONUTF8` / `PYTHONIOENCODING` 环境变量。
- 覆盖抓取、原始页面保存和浏览器 CLI 的输出。无需修改 Windows 系统区域设置，也不关闭 dsh 沙箱。
- 修复 Windows 进程退出时暂停操作被拒绝会中断清理、覆盖原始任务错误的问题；继续清理进程树并等待退出。

## 发布验证

发布流程必须通过 Windows 和 macOS CI，测试后才上传安装包：

- 后端测试及 CP936/CP1252 标准流回归，前端测试和生产构建。
- 在各自系统运行真实 PyInstaller 可执行文件，并再次检查 Electron 包内的后端。
- 使用离线 ACP 模拟服务验证中文、日文、emoji、全角括号、含空格的非 ASCII 路径，以及任务 API → 子进程 → SQLite 的完整传输。
- 使用本地 HTTP 页面验证实际 `--fetch json/raw` 输出和 CLI 错误输出。

ACP 模拟服务替代外部 dsh/付费模型；本版本不宣称修复所有 `cmd.exe 0xc0000142` 问题，也未验证真实店铺上架。
